Predictable REST resources, idempotent writes, signed webhooks and a sandbox that simulates providers, declines and 3DS. Integrate once; routing decides the rest.

Quick startAPI reference
node · create a payment
const payment = await tpp.payments.create({
  amount: 12800,
  currency: "EUR",
  payment_method: { token: "tok_…" },
  routing: { profile: "eu-cards-default" },
  merchant_id: "mer_sample_01",
}, { idempotencyKey: "order-8841" });

// payment.status → "authorized"
// payment.route  → { provider: "acquirer_a", attempt: 1 }
